# Transformer Condition Monitoring



### Project purpose



Exploratory HDR research into electrical power-transformer condition monitoring using vibration, acoustic and current sensing.



The final fault target has not yet been selected. Candidate targets include:



* On-load tap changer faults
* Winding deformation
* Core faults
* Partial discharge
* Other mechanically or electrically observable transformer abnormalities



### Current stage

Literature review and research-question development.



### Current priorities

1. Build a verified literature evidence base.
2. Compare vibration, acoustic and current-sensing methods.
3. Identify gaps that remain under realistic operating conditions.
4. Evaluate external and minimally invasive sensing arrangements.
5. Develop testable candidate research questions.
