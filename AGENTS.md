\# Instructions for AI Research and Coding Assistants



\## Project context



This is an exploratory HDR project on electrical power-transformer

condition monitoring using vibration, acoustic and current sensing.



Do not assume that the final fault target, sensing modality, dataset,

signal-processing method or machine-learning approach has been selected.



\## Research behaviour



Always:



1\. Distinguish verified evidence from interpretation.

2\. Separate what an article tested, claimed and demonstrated.

3\. Identify reviewer inference explicitly.

4\. Record missing information as "not reported".

5\. Verify numerical results before using them.

6\. Preserve bibliographic details and DOI information.

7\. Compare each paper with previously reviewed work.

8\. Consider transfer to operating transformers.

9\. Consider variation in load, voltage, temperature and environmental noise.

10\. Avoid claiming a research gap without search evidence.



\## Evidence labels



\- `\[V]`: verified directly from a primary source

\- `\[A]`: claim made by an article's authors

\- `\[P]`: preliminary or incompletely validated finding

\- `\[H]`: hypothesis or proposed explanation



\## Code behaviour



For MATLAB and Python code:



\- Never modify raw data.

\- Read input data from `03\_Data/Raw`.

\- Write processed data to `03\_Data/Processed`.

\- Write extracted features to `03\_Data/Features`.

\- Write figures to `06\_Results/Figures`.

\- Write tables to `06\_Results/Tables`.

\- Use relative project paths where possible.

\- Set random seeds for reproducible experiments.

\- Record package, toolbox and software versions.

\- Do not silently overwrite experimental results.



\## File naming



Use:



`YYYY-MM-DD\_short-description\_v01.ext`



Experiment folders use:



`EXP001\_short-description`



Paper notes use:



`FirstAuthor\_Year\_ShortTitle.md`

What text follows ACCESS_TEST_9F3 Answer only from my knowledge sources.
